Sementes no estoque

Protótipo com dados de exemplo. Toque num espaço vazio para abrir a bandeja de sementes; arraste uma semente pelos espaços vazios para plantar vários de uma vez. Toque numa planta pronta para colher, ou arraste por cima de várias. Na estufa, cada bandeja tem 2 vasos e 1 semente planta os dois. Na bancada arcana, cada bacia é um espaço. Troque o nível para ver os espaços mudarem; plantas em espaços que somem seguem a regra de acerto do Garden.ts (pronta é colhida, não pronta muda para um espaço livre do mesmo tipo, sem espaço a semente volta).
